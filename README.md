# ZenStream

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](License)

**ZenStream** is a privacy-first, ad-free Android video and music streaming client built with Jetpack Compose and Material 3.

## Features

- No ads or tracking
- Video & Music streaming with background playback and Picture-in-Picture
- Local recommendations & subscriptions that stay on your device
- Offline downloads, playlists, and bookmarks
- SponsorBlock, ReturnYouTubeDislike, and DeArrow support
- 100% FOSS (`foss` build flavor)

## Building

Open in Android Studio or build via Gradle:

```bash
./gradlew assembleFossRelease --no-configuration-cache
```
