# ZenStream

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)

**ZenStream** is an alternative, privacy-friendly Android video streaming client with a clean, distraction-free experience — no ads, no tracking, and direct stream playback by default.

## Features

- No ads or tracking
- Direct video stream playback (`disablePipedProxy` enabled by default) & optional Piped instance support
- Subscriptions & Subscription Groups
- Playlists & Bookmarks
- Watch & Search History (stored locally on device)
- SponsorBlock, ReturnYouTubeDislike, and DeArrow integration
- Offline Downloads & Background Playback

## Building

Open the project in Android Studio or build via Gradle:

```bash
./gradlew assembleDebug --no-configuration-cache
```
